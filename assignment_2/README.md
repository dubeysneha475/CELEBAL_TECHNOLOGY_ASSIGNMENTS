# ShopEase E-Commerce Sales Database

## Celebal Technologies Summer Internship 2026

### Week 2 SQL Assignment

## Objective

The objective of this assignment is to design and analyze an E-Commerce Sales Database using SQL. The project demonstrates SQL concepts including data retrieval, filtering, aggregation, joins, constraints, indexing, CASE statements, transactions, and ACID properties.

## Tools Used

* MySQL Server 8.0
* MySQL Workbench
* SQL

## Database

The project consists of four relational tables:

* Customers
* Products
* Orders
* Order_Items

The tables are connected using Primary Keys and Foreign Keys to maintain referential integrity.

## Concepts Covered

* SELECT Statements
* WHERE Clause
* Constraints
* Primary Keys
* Foreign Keys
* Indexes
* GROUP BY
* Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)
* HAVING Clause
* INNER JOIN
* LEFT JOIN
* CASE Statements
* ACID Properties
* SQL Transactions (COMMIT & ROLLBACK)

## Learning Outcomes

* Designed and created relational database tables.
* Applied SQL constraints and indexes for data integrity and performance.
* Performed data filtering and aggregation using SQL queries.
* Combined data from multiple tables using JOIN operations.
* Implemented conditional logic using CASE statements.
* Understood ACID properties and transaction management.
* Maintained referential integrity using Primary and Foreign Keys.
