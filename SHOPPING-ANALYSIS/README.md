# Assignment 1 - Data Exploration and Cleaning Using Pandas

## Objective

To learn Python basics and perform data exploration and cleaning using Pandas.

## Tasks Performed

* Loaded the ecommerce dataset into a Pandas DataFrame.
* Explored the dataset using `head()`, `tail()`, `shape`, `columns`, and data types.
* Identified and handled missing values.
* Performed data selection and filtering operations.
* Checked for and removed duplicate records.
* Created derived columns: `discount_amount` and `total_amount`.
* Saved the cleaned dataset as `cleaned_dataset.csv`.

## Files Included

* `Analysis.ipynb`
* `combined_dataset.csv`
* `cleaned_dataset.csv`

## Tools Used

* Python
* Pandas
* Jupyter Notebook
* VS Code

## Output

A cleaned and processed ecommerce dataset ready for further analysis.
